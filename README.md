# সস্তা জেরক্স এন্ড অনলাইন সেন্টার — Website

এটি একটি সম্পূর্ণ static website। কোনো server/database লাগবে না।

## GitHub Pages-এ প্রকাশ করার নিয়ম
1. GitHub-এ নতুন repository তৈরি করুন, যেমন `sasta-xerox-website`
2. `index.html` এবং `style.css` আপলোড করুন।
3. Repository → **Settings → Pages**
4. Source হিসেবে **Deploy from a branch** নির্বাচন করুন।
5. Branch: `main` এবং folder: `/ (root)` নির্বাচন করে Save করুন।
6. কিছুক্ষণ পর GitHub Pages-এর website link পাওয়া যাবে।
